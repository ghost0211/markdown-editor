# MarkdownEditor v2.0.0

## 图片与附件资源管理

- 顶部「资源」集中查看当前文档的图片、内嵌资源和本地附件，支持搜索、类型/失效筛选、图片预览、完整地址复制、文件大小与引用位置。
- 可定位正文、导出原始资源、在文件管理器中显示本地文件。导出单项资源上限 32 MiB，不执行附件中的 HTML 或脚本。
- 已保存普通 Markdown 可将单张或全部内嵌图片转存到旁边 `assets/`；新资源不覆盖已有文件，失败批次安全回滚，正文修改可撤销。XMD 资源继续保存在包内。

## 增强全文查找替换

- `Ctrl+Shift+F` / `Ctrl+H` 打开高级查找替换；原 `Ctrl+F` 保留编辑器快速查找。
- 支持当前文档/全部已打开文档、大小写、Unicode 全词、正则和跳过代码，按文档分组并定位正文。
- 替换前显示前后预览；多文档替换整体校验内容，过期结果拒绝部分应用，各标签页可撤销。
- 默认保护内嵌图片与附件的 Base64 数据；原编辑器替换栏也阻止误改隐藏资源。
- 搜索和替换计算在独立 Worker 中运行，支持超时终止；结果限制为每文档 1000 条、总计 5000 条，截断时禁止不完整的全部替换。

## XMD 性能与保存可靠性

- XMD 改为同目录临时文件完整写入、同步后原子替换；写入或提交失败时保留旧包。
- 保存按目标路径排队；较晚的另存为不会被较早操作覆盖，自动保存写盘前重新检查外部修改。
- 对全部内嵌资源使用总计 64 MiB 的内存 LRU，正文变化时复用已压缩资源，跳过重复 Base64 解码与资源压缩；本地和网络资源每次重新读取。
- XMD v1 格式及签名更新公钥保持不变；仍是生成并原子写入完整 ZIP，不是增量追加。

## 本地历史版本

- Markdown / XMD 手动保存和自动保存后创建快照，连续相同内容不重复记录，关闭标签不删除历史。
- 顶部「历史」可选择快照、查看与当前正文的并排差异、恢复到可撤销编辑缓冲区；恢复不直接覆盖磁盘文件。
- 默认每文档 50 个快照、总计 64 MiB，优先淘汰最旧版本；快照与索引原子写入，并校验正文大小和 SHA-256。
- 快照仅存于应用数据目录，明文、本机保存，不上传、不依赖 Git。XMD 快照包含当前内嵌资源；外置资源文件的历史内容不另存副本。

## 模板与常用片段

- 内置会议纪要、周报、技术方案、读书笔记的中英双语 GFM 模板。
- 支持自定义片段的新建、编辑、删除，以及日期、时间、标题和作者变量；仅做文本替换，不执行代码。
- 可新建文档或插入光标处。最多保存 50 个片段，单个正文最多 256 KiB。

## 文档质量检查

- 检查标题层级跳跃、空标题、空链接、图片空 alt、未闭合代码块/元数据、重复标题及本地资源缺失/不可解析。
- 支持按错误、提醒、信息筛选并定位正文；不误报代码、公式和 HTML 注释。
- 本地资源只查询元数据，不读取资源正文，不请求远程链接；检查面板不自动改写文档。

## 导出样式主题

- 顶部「导出主题」提供固定字体、字号、浅色/护眼复古/深色配色、封面、目录、页眉和可选页码，最多保存 10 个本地预设。
- 实际应用于 Word、PDF、HTML；Word 支持真实目录域、封面、页眉和可选页码页脚。
- PDF 页码由 Edge 原生打印页眉页脚提供；自定义页眉文字用于 HTML/Word。HTML 页码采用渐进增强，浏览器不支持时不伪造页码。
- 未保存自定义主题时保持原有导出行为；XMD 打包格式不受影响。

## 文件夹工作区

- 顶部「工作区」切换到文件夹树，可原生选择目录、打开文档、刷新、新建文档/文件夹及同目录重命名。
- 同步已打开标签的路径和指向旧路径的本地链接/图片，修改可撤销并保留未保存状态；历史快照仍保留原路径。
- 文件操作限制在所选目录内，不覆盖已有目标，不跟随符号链接，禁止根目录改名或目录移入自身。
- 最多显示 5000 项、深度 12，跳过隐藏目录、依赖与构建目录；扫描不读取文件正文。

## 验证与安装

- 发布前已通过 831 项前端测试、61 项 Rust 测试，以及 ESLint、TypeScript、生产构建和 Rust Clippy 检查。
- 已通过 Chrome 实际交互验证资源管理、跨文档替换、历史恢复、模板、质量定位、工作区及主题化 HTML 导出。
- Windows 推荐下载 NSIS `x64-setup.exe`，也提供 MSI；发布包使用现有公钥签名，旧版可从「偏好设置 → 软件更新」升级。
