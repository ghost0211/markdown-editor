# MarkdownEditor v2.0.3

## 可视化编辑

- 编辑与分屏视图新增「源码模式 / 可视化模式」切换，并可在偏好设置中选择默认编辑方式；选择自动记忆，旧配置仍默认使用源码模式。
- 标题、粗体、斜体、删除线、行内代码、列表、引用、链接文字与图片可直接在编辑区呈现；当前光标或选区所在行展开源码，移开后恢复渲染。
- 标题工具合并为「正文 / H1–H6」下拉，工具栏与选区浮动格式栏会反映当前格式；已有行内格式可再次点击取消。
- 任务列表复选框可直接勾选，作为局部 Markdown 编辑进入撤销与重做。
- 公式、Mermaid、代码块、HTML、前置元数据及不支持的复杂结构始终保留源码回退，不经过 HTML 往返转换。

## 可编辑表格

- 标准顶层 GFM 表格可呈现为编辑网格，直接修改单元格中的 Markdown 文本。
- 支持插入或删除行列、设置左对齐、居中、右对齐或默认对齐；结构性修改可撤销。
- 支持 `Tab` / `Shift+Tab` 切换单元格、`Enter` / `Shift+Enter` 上下移动、`Escape` 回到当前单元格源码。
- 单元格聚焦时使用顶部行内格式工具会定位该格源码，不会误改正文中的旧光标位置；块级操作不会强行破坏表格。
- 为避免数据丢失，非矩形、缺外侧竖线、嵌套容器、含图片或内嵌资源载荷的表格保留源码编辑。网格模式最多 100 行（含表头）、20 列、64 KiB。

## 图片上下文工具

- 点击图片可修改替代文本和图片地址、选择本地图片文件替换，或返回源码编辑。
- 移除图片需要二次确认，只移除当前引用，不删除磁盘文件或其他共享引用；操作可撤销。
- 替换文件最大 32 MiB，采用内嵌图片并随 Markdown / XMD 正常保存。
- 修改引用式图片的地址只替换当前使用，不影响其他共用定义的图片。
- 编辑大体积内嵌图片的替代文本不会把 Base64 载荷复制到编辑表单，也不会改写原始资源字节。

## 浮动格式栏与快速插入

- 选中普通文字后显示加粗、斜体、删除线、行内代码和链接工具；支持 `Alt+F10` 聚焦、`Tab` 切换和 `Escape` 关闭。
- 普通行首输入 `/` 可搜索并插入正文、标题、列表、任务、引用、代码块、表格、图片、链接或分隔线，支持中英文检索。
- 方向键选择，`Enter` / `Tab` 插入，`Escape` 仅取消菜单并保留查询文本；插入与查询删除合并为一次可撤销操作。
- 输入法组合期间不抢占候选确认键；代码、公式、表格、HTML 和资源地址等受保护范围不会弹出不适用工具。

## 兼容与验证

- Markdown 源文仍是唯一数据源，模式切换不改正文、不清空撤销历史；Markdown / XMD 保存、图片与附件打包、文件关联和自动更新保持兼容。
- 已通过 1032 项前端测试、62 项 Rust 测试，以及 ESLint、TypeScript、生产构建和 Rust Clippy 检查。
- 已验证中英文界面、明暗主题、窄窗口、表格连续输入与撤销、图片替换、浮动栏键盘操作、`/` 菜单插入及重启后的模式记忆。
- 已在生产构建和桌面 CSP 下验证表格、图片与快速插入功能，并完成可视化修改后的 XMD 图片与附件往返测试。

Windows 推荐下载 NSIS `x64-setup.exe`，也提供 MSI；旧版可通过「偏好设置 → 软件更新」升级。
