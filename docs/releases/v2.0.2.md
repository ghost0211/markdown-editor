# MarkdownEditor v2.0.2

## 修复图片导致的统计失真

- 修复含内嵌图片或附件时，Base64 数据被当作正文计入字数、字符数和预估阅读时间的问题。
- 字数、字符数及预估阅读时间不再包含内嵌资源载荷；图片替代文本仍正常计入，源码行数保持不变。
- 覆盖普通 Markdown 图片、引用式图片、HTML `src` / `srcset` 和内嵌附件链接，包括未使用的引用定义。
- 代码示例中的文本不会被误当作实际图片资源；普通纯文本文档的统计行为不变。
- 使用轻量资源范围扫描，避免统计大图片时额外完整解析 Base64 内容。
- 仅修正统计口径，不修改、压缩或移除文档中的原始图片与附件数据。

## 移除左上角重复品牌区

- Windows 原生标题栏已有应用名称，应用内标题栏不再重复显示 MD 图标和「Markdown Editor」文字。
- 释放的空间用于文档操作；新建、打开、保存、另存为、工具、导出、搜索、视图切换和设置入口保持不变。
- 工作区/大纲切换、快捷键、文件关联、文档保存与自动更新行为不变。

## 验证

- 已通过 839 项前端测试、62 项 Rust 测试，以及 ESLint、TypeScript、生产构建和 Rust Clippy 检查。
- 已通过真实浏览器验证约 20 万字符的内嵌图片载荷不再影响统计，原始文档内容保持不变。
- 已验证去除重复品牌区后，文档工具、工作区、质量检查、历史与主题导出的全部入口仍正常。

Windows 推荐下载 NSIS `x64-setup.exe`，也提供 MSI；旧版可通过「偏好设置 → 软件更新」升级。
