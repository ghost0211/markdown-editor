# MarkdownEditor v1.9.0

## 新增 XMD 单文件导出

- 顶部「导出」菜单新增 **导出 XMD 文档**，将 Markdown 正文、引用图片及正文链接到的本地附件打包成一个 `.xmd` 文件，方便分享与归档。
- XMD v1 使用标准 ZIP 容器，包含 `document.md`、`manifest.json` 与 `assets/`；正文资源引用自动改写为包内相对路径，同一解析地址的资源只保存一份。
- 支持本地图片、HTTP/HTTPS 图片、粘贴的内嵌图片、引用式 Markdown 图片，以及 HTML `img` / `picture` / `srcset` 图片。
- 保留 Markdown 原有排版、换行、Front Matter、数学公式与 Mermaid 源码；不修改原文档、保存路径或未保存状态。

## 可靠性与安全防护

- 资源缺失、下载失败或超出限额时明确中止，不静默生成缺图包；单资源上限 32 MiB，正文与资源总量上限 128 MiB，最多 2048 个不同资源。
- 修复带 UTF-8 BOM 文档的资源地址偏移，以及图片片段标识含括号时的 Markdown 转义问题。
- 支持中文、空格、百分号及编码后的 `#` / `?` 文件名；防止同名资源相互覆盖。
- 本地资源在原生读取前检查大小，使用专用二进制 IPC 读取本地资源与写入整包，避免大文件转成 JSON 数字数组。
- `//cdn.example/image.png` 按 HTTPS 下载；拒绝 UNC 网络共享及远程 `file://host` 资源，避免隐式 SMB 访问。
- 网络请求设有超时，不携带应用 Cookie、Authorization 或 Referer；导出目标强制使用 `.xmd` 扩展名并保护源文档路径。

## 使用与兼容说明

1. 打开或编辑 Markdown，选择「导出 → 导出 XMD 文档」。
2. **当前仅支持导出**，尚不支持直接打开或编辑 `.xmd`，也未注册系统文件关联。可用 ZIP 工具完整解压后打开 `document.md`，并保留同级 `assets/` 目录。
3. Web 模式无法按本地路径读取附件；含本地资源的文档建议使用桌面版导出。
4. **只导出并分享可信文档**：正文引用的本地附件内容会实际收入包内（包括目录外、绝对路径和本地 `file://` 引用）；联网图片也会实际访问对应 URL，包括本机及内网 HTTP 服务。分享前请检查资源，避免带出敏感文件。
5. v1 不递归打包 CSS、SVG 内部外链、音视频或链接文档的依赖，也暂无整包取消按钮。

完整格式说明：https://github.com/ghost0211/markdown-editor/blob/v1.9.0/docs/xmd-format.md
