# MarkdownEditor v2.0.4

## 修复可视化模式的分割线

- 修复可视化模式下 `---`、`***`、`___` 仍显示为原始文本的问题，现渲染为真正的水平分割线。
- 光标或选区进入分割线所在行时自动恢复 Markdown 源码，移开后重新渲染，与标题、列表等即时渲染行为一致。
- 前置元数据、Setext 标题下划线、围栏代码块和表格分隔行不会被误判为分割线。
- 仅在显示层渲染，不改写文档；保存、复制、XMD 打包与源码模式的内容保持不变。

## 验证

- 已通过 1034 项前端测试、62 项 Rust 测试，以及 ESLint、TypeScript、生产构建和 Rust Clippy 检查。
- 已在真实浏览器与生产构建中验证三种分割线标记、光标回到源码、模式切换和文档内容保持不变。

Windows 推荐下载 NSIS `x64-setup.exe`，也提供 MSI；旧版可通过「偏好设置 → 软件更新」升级。
