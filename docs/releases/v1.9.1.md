# MarkdownEditor v1.9.1

## 图片编辑体验优化

- **图片地址不再铺满编辑区**：拖入或粘贴产生的 Base64 图片显示为「内嵌图片/文件名」，本地与网络图片显示为紧凑的短路径。
- 鼠标悬停图片地址可查看完整内容、复制地址；点击地址可修改，支持撤销/重做。也可在图片地址旁按 `Ctrl+Enter` 打开修改面板。
- 只改变编辑器的显示方式，保存、复制、预览和 XMD 导出仍保留真实图片数据；已有文档自动生效，无需重新插图。
- 保护隐藏地址的编辑边界，输入、粘贴或拖入新图片不会误插入 Base64 数据；支持 Windows 路径与特殊字符的安全转义。

## XMD 打开、编辑与文件关联

- **`.xmd` 成为可直接打开和编辑的文档格式**，不再只能导出后用 ZIP 工具查看。
- 打开对话框、拖放、最近文件、Windows 系统唤起与单实例文件关联均支持 `.xmd`；设置的「已支持格式」同步显示 `.xmd`。
- 直接打开 XMD 时，包内图片和附件安全载入内存，不在旁边解压出资源目录；编辑后保存会重新打包，保留资源与 Markdown 正文。
- 在已打开的 XMD 中继续拖入图片，保存后直接收入包内，不额外创建外置 `assets/` 目录。
- 包内图片正常预览；SVG 只作为图片显示。附件点击后以普通数据文件下载，不执行包内 HTML 或脚本。
- 普通文本 Markdown 的读写、保存快照与外部文件变更检查行为保持不变。

## 安全与可靠性

- 读取前限制 XMD 压缩包大小；解析中央目录并限制资源数、单资源大小和解压总量。
- 通过有大小上限的流式解压处理资源，拒绝伪造声明尺寸、ZIP 炸弹、路径穿越、重复条目、缺失资源、未知版本及包外资源引用。
- 校验 ZIP 本地/中央目录结构和资源 CRC；损坏或缺图的 XMD 会明确报错，不会静默丢图。
- 沿用现有更新签名公钥，发布签名 NSIS、MSI 安装包及 `latest.json` 更新清单。

## 使用说明

- **图片地址折叠**：悬停查看/复制，点击修改；真实源文不会改成显示用的短名称。
- **打开 XMD**：选择「打开」或直接双击关联文件；修改后正常保存即可。
- **文件关联生效**：Windows 需安装本版后，再在系统「默认应用」中选择 MarkdownEditor；不会强制改变用户默认应用。
- XMD 读取采用现代 WebView 的流式解压能力；请保持系统 WebView2 为正常受支持的版本。
