# MarkdownEditor v2.0.1

## 更清晰的界面层级

- **顶部不再平铺全部功能**：保留新建、打开、保存、另存为与导出等高频操作，保存作为主要操作突出显示。
- **新增「文档工具」菜单**：资源管理、模板与片段、文档质量检查、本地历史统一归入工具菜单，使用简短标签与辅助说明。
- **导出主题并入导出菜单**：与 Word、PDF、HTML、XMD、富文本复制一起管理，不再长期占用顶部独立按钮。
- 工作区、搜索、文档对比、视图切换、主题、设置与快捷键帮助仍保留原有入口。

## 响应式与视觉优化

- 窗口变窄时自动收起文字标签，保留清晰图标、工具提示与主要操作，避免顶部拥挤。
- 优化标签页的活动边框、留白与未保存状态，统一格式工具栏的按钮尺寸与分组间距。
- 状态栏保留字数、行列、保存状态、编码与模式信息，改善数字对齐和紧凑布局。
- 文档工具菜单与导出菜单支持方向键导航、Esc 关闭及焦点恢复，同时支持浅色和深色主题。

## 兼容性与可靠性

- 本版仅调整界面组织与交互呈现，不改变 Markdown / XMD 文档格式、保存策略、文件关联或更新签名公钥。
- 原有全部功能入口与快捷键保持不变；工作区和大纲仍可互相切换。
- 文档、模板、历史、资源管理及导出内容不会因菜单位置调整而改变。

## 验证

- 已通过 831 项前端测试、62 项 Rust 测试，以及 ESLint、TypeScript、生产构建和 Rust Clippy 检查。
- 已通过真实 Chrome 浏览器验证资源、模板、质量、历史、工作区、导出主题和实际 HTML 导出。
- 已检查浅色、深色和窄窗口布局，验证菜单键盘导航、焦点恢复及不透明最终显示状态。

Windows 推荐下载 NSIS `x64-setup.exe`，也提供 MSI；旧版可通过「偏好设置 → 软件更新」升级。
