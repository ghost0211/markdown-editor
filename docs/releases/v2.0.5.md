# MarkdownEditor v2.0.5

## 补齐可视化模式未渲染的内容

- **中文邻近强调**：修复 `采用**“双下拉字典级联选择”**的…`、`**重点（备注）**后文` 等写法仍显示星号的问题。编辑器解析器新增与阅读预览一致的中文引号/括号强调规则，英文与普通 Markdown 解析结果保持不变。
- **代码块与图表**：顶层围栏代码显示为带语言标签和「复制代码」的代码框，不再是带反引号的源码；` ```mermaid ` 直接渲染图表，切换明暗主题时自动重新渲染。点击代码框或图表即可回到该块源码编辑。
- **表格单元格富文本**：单元格未编辑时显示渲染后的粗体、斜体、删除线、行内代码和链接；点击进入编辑后显示原始 Markdown，退出后重新渲染。编辑、撤销与 `Tab` / `Enter` / `Escape` 导航行为不变。

## 边界与安全

- 列表/引用内的代码块、缩进代码、超过 200 KB 或 800 行的代码块继续保留源码，避免块控件移位或大内容卡顿。
- 公式（`$…$`、`$$…$$`）、HTML 与前置元数据仍为源码回退。
- 所有渲染仅作用于显示层，Markdown / XMD 源文、复制内容与导出结果不变；代码块中的图片语法不会被当作图片加载。

## 验证

- 已通过 1050 项前端测试、62 项 Rust 测试，以及 ESLint、TypeScript、生产构建和 Rust Clippy 检查。
- 已在真实浏览器与生产构建（桌面 CSP）下验证中文引号粗体、表格单元格富文本、代码框复制、Mermaid 渲染、主题切换与源码模式切换。
- 已验证可视化修改后的文档内容与源文逐字一致，XMD 图片/附件打包流程不受影响。

Windows 推荐下载 NSIS `x64-setup.exe`，也提供 MSI；旧版可通过「偏好设置 → 软件更新」升级。
